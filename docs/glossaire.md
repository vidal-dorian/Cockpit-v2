# Glossaire

Un seul nom par notion dans l'interface (décision 093). Le brief (§4 Vocabulaire) fait foi ; ce tableau fixe les cas où deux noms se disputaient une notion. Pour changer un nom, change cette page et la décision 093.

| Notion | Nom retenu | À ne pas dire | Précision |
|---|---|---|---|
| Ce que l'humain dépose et que Claude développe (un objet, avec un numéro) | **Ticket** | idée (pour l'objet) | Le mot « Idée » reste, car c'est le nom de la première étape : la colonne « Idées » du Kanban, l'onglet et la barre de saisie « Idée » du téléphone, « Idée notée dans … » (045 B, 055 D, 071 C, non rouvertes). Une idée est un ticket à l'étape Idée |
| Les fichiers `.claude/rules` d'un projet | **Règles du code** | Règles (seul) | Puce de l'onglet Claude |
| Les règles métier d'une US de reprise (onglet Conception) | **Règles** | écran de reprise | Les liens disent « l'onglet Règles » |
| La trace globale, tous projets | **Journal** | Historique | Page `/journal`, filtrable |
| La trace d'un seul projet | **Historique** | Journal | Onglet du projet. Sa première puce « Journal » est la vue du Journal filtrée sur ce projet (062). Deux écrans, deux noms |
| Une tâche planifiée sur claude.ai, que Cockpit crée dans le compte de l'utilisateur | **Tâche cloud** | | Réglages › « Tâches cloud » (054 A). Ex. : Écrire les US, le Lanceur Cockpit. Les runs sur ce PC passent par Claude Desktop, pas par une tâche cloud |
| La tâche cloud unique qui lance tout ce que Cockpit exécute dans le cloud (runs, routines, file, nuit) | **Lanceur** | | Le « Lanceur Cockpit » (054 A), créé une fois sur claude.ai. C'est une tâche cloud parmi d'autres, pas un synonyme |
| Un travail que Claude refait régulièrement, défini dans Cockpit | **Routine** | | Une routine est lancée par le Lanceur |
| La page qui liste la tâche Écrire les US et les routines | **Tâches programmées** | | Page `/claude/taches` (056 F). C'est le nom de la page, pas d'une notion : on y trouve des tâches cloud et des routines |
| La trace d'une seule US | **Historique** (section de la page d'une US) | | Section de la page d'une US (StoryDecisions) : ce qui s'est passé pour cette US, pas pour le projet. Même mot, périmètre dit par la page où l'on se trouve |
